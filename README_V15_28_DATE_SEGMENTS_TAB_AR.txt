الإصدار 15.28 — تاريخ مقسّم والتنقل بزر Tab

- التاريخ يظهر بثلاث خانات متجاورة: اليوم، الشهر، السنة.
- زر Tab ينقل المؤشر من اليوم إلى الشهر ثم السنة.
- يدعم لصق 8 أرقام مثل 23102026 في أي خانة، وتتحول إلى 23/10/2026.
- يقبل التواريخ القديمة ولا يفرض تاريخ اليوم.
- الرزنامة تحدّث الخانات الثلاث، ويُرسل التاريخ إلى قاعدة البيانات بصيغة يوم/شهر/سنة.
- فحص Python syntax ناجح؛ يلزم اختبار الواجهة في متصفح Windows على الجهاز.
