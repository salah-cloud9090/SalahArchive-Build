الإصدار 15.40 — تحسين اختيار الماسح وإصلاح حقل التاريخ

1) صفحة المسح تعرض قائمة بأجهزة المسح التي يكتشفها Windows WIA، وتتيح حفظ اختيار الجهاز ضمن scan_preferences.json.
2) عند اختيار جهاز محدد، يحاول النظام الاتصال به مباشرة؛ وإذا بقي الاختيار فارغاً، يفتح نافذة اختيار الماسح من Windows.
3) إصلاح CSS لحقل التاريخ: منع قواعد الحقول العامة من تقليص خانات اليوم والشهر والسنة، وتوسيع خانة السنة وتثبيت عرضها.
4) تعديل زر الرزنامة: إزالة عنصر التاريخ المخفي من فوق الزر حتى لا يعترض النقر، واستدعاء نافذة التاريخ من الزر مباشرة.
5) التاريخ يبقى قابلاً للإدخال كتاريخ قديم، وتبقى خانات اليوم/الشهر/السنة منفصلة مع دعم Tab.

مهم:
- قائمة الأجهزة تعرض الأجهزة التي يراها Windows عبر WIA فقط؛ بعض تعريفات TWAIN فقط قد لا تظهر.
- تم فحص صياغة Python، لكن لا يمكن اختبار جهاز ماسح فعلياً في بيئة البناء. اختبره على الحاسبة بعد تشغيل البرنامج.
- لا تستبدل قاعدة البيانات ولا تحذف ملفات الأرشيف. فك الحزمة في مجلد جديد وخذ نسخة احتياطية قبل التجربة.
