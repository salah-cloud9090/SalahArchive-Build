ما يتضمنه هذا الإصدار:
- ملفات البرنامج الموجودة في حزمة V15.1 الأصلية.

- استبدال reset_test_database.bat بنسخة أوضح لا تعتمد على PowerShell لإنشاء ختم الوقت.

التشغيل:

2. شغّل run_local_archive.bat لتشغيل البرنامج.
3. لا تشغّل reset_test_database.bat إلا إذا أردت إعادة تهيئة بيانات الاختبار فعلاً.

تنبيه:
إعادة التهيئة تحذف قاعدة البيانات المحلية الحالية ومجلدات العمل بعد محاولة نسخها إلى backups.
احتفظ بنسخة مستقلة من المجلد قبل استخدامها. إذا فشلت عملية النسخ الاحتياطي، يجب إلغاء العملية وعدم المتابعة.

التحقق:
تم فحص صياغة ملفات Python ضمن الحزمة وفحص توافق main.py مع صياغة Python 3.11.
هذا لا يعادل اختباراً كاملاً لجميع وظائف التطبيق على جهاز Windows الفعلي.
