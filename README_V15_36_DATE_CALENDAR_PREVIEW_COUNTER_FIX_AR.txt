الإصدار v15.36 — إصلاح الرزنامة والتنقل وعدّاد صفحات المعاينة

1) حقل التاريخ مقسم إلى يوم / شهر / سنة، وTab ينتقل بين الأجزاء دون نقل الصفحة. بعد السنة ينتقل Tab إلى الحقل التالي.
2) إدخال 8 أرقام مثل 23102026 يعبئ التاريخ إذا كان صالحاً.
3) زر الرزنامة أصبح قابلاً للنقر فعلياً عبر حقل التاريخ الأصلي المتموضع فوق الزر.
4) معاينة PDF تعرض «صفحة X من N»، وتمنع تجاوز أول وآخر صفحة. الملفات المصورة متعددة الإطارات تعرض عدد الإطارات إذا أمكن قراءته.

مهم: فُحصت صياغة Python محلياً؛ يجب اختبار الرزنامة والتنقل على جهاز Windows قبل اعتماد النسخة في العمل. احتفظ بنسخة احتياطية من قاعدة البيانات.
