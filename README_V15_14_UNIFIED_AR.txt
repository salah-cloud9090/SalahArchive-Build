الإصدار 15.14 — حزمة موحدة أولية للتشغيل والتشخيص والنسخ الاحتياطي

ما الجديد:
- START_HERE.bat: نقطة تشغيل موحدة؛ تفحص المكتبات وتحاول أولاً التثبيت من offline_packages إن كانت حزم wheel موجودة، ثم تسألك قبل محاولة الإنترنت.
- BACKUP_NOW.bat: نسخة احتياطية مؤرخة من قاعدة SQLite ومجلد المستندات، باستخدام SQLite online backup حتى أثناء عمل البرنامج.
- DIAGNOSTICS.bat: فحص محلي للبيئة وTesseract ولغة ara والمنفذ وLM Studio؛ يحفظ diagnostics_report.txt ولا يرفع بياناتك.
- تم تصحيح اسم مجلد المشروع وتوحيد نقطة الدخول، مع الاحتفاظ بقاعدة البيانات الحالية إن نقلتها إلى هذا المجلد.

تنبيه مهم بشأن العمل دون إنترنت:
هذه الحزمة لا تتضمن حتى الآن مثبت Python محمولاً، ولا كل ملفات wheel، ولا مثبت Tesseract وبيانات ara، ولا نموذج LM Studio. لذلك لا يمكن اعتبارها تثبيتاً كاملاً offline بعد. START_HERE يحاول استخدام offline_packages إذا جهزت الحزم داخله، وإلا يوضح أن التثبيت قد يحتاج إنترنت. يلزم تجهيز هذه الملفات من مصادرها الرسمية ومطابقة 64/32-bit وإصدار Windows قبل ضمان التثبيت offline.

قاعدة البيانات والشبكة:
- لا تشغّل reset_test_database.bat على بيانات فعلية.
- قبل نقل القاعدة إلى هذا المجلد، أوقف البرنامج وخذ نسخة احتياطية ثم انسخ docuware_archive.db ومجلد local_archive_files معاً.
- وضع الشبكة موجود لكنه HTTP وغير مشفر؛ لا تفعّله خارج LAN موثوقة/VPN، ولا تفتح المنفذ على الإنترنت.
- قاعدة SQLite ملائمة كبداية محلية/اختبار. لا تشارك ملف SQLite نفسه مباشرة من مجلد شبكة بين عدة أجهزة؛ عند تعدد المستخدمين المتزامنين نختبر خادماً مركزياً وقاعدة بيانات مناسبة بعد النسخ الاحتياطي.

الفحوص التي أجريت على هذه الحزمة:
- صياغة Python لجميع الملفات.
- إنشاء قاعدة بيانات مؤقتة وتشغيل initialize() وفحص SQLite integrity.
- تجربة إنشاء نسخة احتياطية وفتح ZIP وفحص سلامتها.
- فحص تكوينات التشغيل؛ لا يشمل ذلك اختبار Canon الفعلي أو أجهزة الشبكة الأخرى.
