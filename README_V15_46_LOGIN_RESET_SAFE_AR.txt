الإصدار v15.46 FIXED — إصلاح تشغيل أداة إعادة تعيين كلمة المرور

المشكلة السابقة:
ملف BAT كان يحتوي نصوصاً عربية بترميز UTF-8، وبعض إصدارات Windows CMD فسّرتها كأوامر غير معروفة.

الإصلاح:
- ملف RESET_ADMIN_PASSWORD.bat يحتوي الآن أوامر ASCII فقط، ويجرب py -3 ثم python.
- أداة التعيين تنشئ نسخة احتياطية مؤرخة من docuware_archive.db قبل تعديل كلمة المرور.
- تُحدّث كلمة مرور المستخدم admin الموجود فقط، ولا تحذف الكتب أو المجالس أو السلال.
- عند عدم العثور على قاعدة البيانات أو جدول المستخدمين، تتوقف دون إعادة تهيئة البيانات.

طريقة الاستخدام:
1. أغلق التطبيق والمتصفح.
2. شغّل RESET_ADMIN_PASSWORD.bat.
3. أدخل كلمة مرور جديدة من 12 حرفاً على الأقل مرتين.
4. شغّل START_HERE.bat وسجّل الدخول باسم admin وكلمة المرور الجديدة.

إذا ظهرت رسالة أن Python غير موجود، لا تتابع بتخمين الأوامر؛ أرسل صورة الرسالة.
