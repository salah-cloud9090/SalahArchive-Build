الإصدار V15.2 — تعديل ملف المعاملة

- إضافة زر «تعديل المعاملة» في سجل المعاملات.
- إضافة زر «تعديل بيانات المعاملة» داخل ملف المعاملة.
- تعديل رقم المعاملة والعنوان والنوع والحالة والأولوية والقسم والمسؤول وتاريخ الاستحقاق والملاحظات.
- التحقق من الحقول المطلوبة ومن عدم تكرار رقم المعاملة.
- تسجيل التعديلات في سجل إجراءات المعاملة وسجل التدقيق.
- تعديل البيانات لا يحذف الكتب المرتبطة أو المرفقات.

التشغيل:
1. فك ضغط الحزمة في مجلد جديد.
2. شغّل run_local_archive.bat.
3. افتح «المعاملات» ثم «تعديل المعاملة»، أو افتح ملف معاملة واضغط «تعديل بيانات المعاملة».

تم فحص صياغة ملفات Python، لكن يلزم اختبار الحفظ والتعديل والرفع داخل Windows قبل الاستخدام الرسمي.
