# Administrative AI System V9 — واجهة الأرشفة والذكاء المحلي

## قبل التشغيل
1. أوقف النسخة القديمة وخذ نسخة احتياطية من `docuware_archive.db` ومجلد `local_archive_files`.
2. فك الضغط في مجلد جديد، ولا تنقل قاعدة البيانات فوق نسخة قديمة قبل الاحتفاظ بنسخة احتياطية.
3. شغّل `install_dependencies.bat` ثم `run_local_archive.bat`.
4. افتح `http://127.0.0.1:8765`.

## سير العمل
1. افتح «السلال والمسح».
2. امسح من Canon عبر Windows WIA (إذا كان تعريف الجهاز يدعم ذلك) أو ارفع PDF/صورة إلى السلة.
3. اضغط «OCR والذكاء» لاستخراج النص ثم طلب اقتراحات من LM Studio المحلي.
4. راجع النتيجة، ثم افتح «فهرسة ومعاينة» لتظهر حقول الفهرسة مع الملف.
5. صحّح الحقول بنفسك واضغط حفظ.

## وظائف V9
- روابط واضحة في شريط التنقل لكل الوحدات المتوفرة.
- خطوات ظاهرة من السلة إلى OCR/الذكاء ثم الفهرسة.
- عارض PDF/صور داخل تفاصيل المستند مع أدوات طباعة/تكبير/تصغير/تدوير للعرض.
- حفظ ملاحظات المراجعة والنصوص المهمة المرتبطة بالسجل.
- توجيه نموذج LM Studio لعدم تخمين القيم وإضافة مؤشرات ثقة ومراجعة عندما يستطيع النموذج الالتزام بالتنسيق.
- استمرار استخدام SQLite كما في النسخة السابقة.

## متطلبات الذكاء وOCR
- شغّل LM Studio Local Server على `127.0.0.1:1234` وحمّل نموذجاً مناسباً يدعم العربية.
- OCR للملفات المصورة يحتاج Tesseract OCR مثبتاً مع بيانات اللغة العربية `ara`، إضافة إلى المكتبات الموجودة في `requirements.txt`.
- إذا تعذر OCR أو الاتصال بالنموذج، راجع النص/الرسالة ولا تعتمد بيانات غير مؤكدة.

## حدود مهمة
- التدوير والتكبير أدوات عرض ولا تعدّل الملف الأصلي.
- ملاحظات التظليل تحفظ كنص مرتبط بالسجل؛ هذا الإصدار لا يرسم علامات تظليل دائمة داخل صفحات PDF.
- الطباعة تعتمد على دعم عارض PDF في المتصفح.
- دعم المسح المباشر يعتمد على تعريف Windows WIA الخاص بالماسح.
- MySQL إعداد/اختبار وترحيل اختياري؛ SQLite تبقى قاعدة التطبيق في هذا الإصدار.
- هذه النسخة اجتازت فحص صياغة Python، لكن يلزم اختبارها على حاسبتك مع ملف ممسوح حقيقي وLM Studio وCanon قبل اعتمادها رسمياً.
