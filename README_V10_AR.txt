# V10 — ربط قراءة النص بالذكاء الاصطناعي المحلي

## لماذا كانت صفحة /process تعرض النص فقط؟
صفحة /process كانت تنفذ استخراج النص/OCR ثم تعرض النتيجة، ولا تحتوي على خطوة ثانية لإرسال النص إلى LM Studio. لذلك ظهور النص لم يكن يعني أن الذكاء الاصطناعي حلّل المستند.

## الجديد في V10
- إضافة زر «تحليل بالذكاء الاصطناعي المحلي واستخراج بيانات الكتاب» إلى نتيجة استخراج النص.
- إضافة مسار `/analyze-extracted` الذي يرسل النص إلى LM Studio المحلي ويعرض اقتراحات رقم الكتاب والتاريخ والجهات والموضوع والقسم والسرية وغيرها.
- عرض رسالة واضحة إذا لم يكن LM Studio يعمل.
- لا يتم اعتماد اقتراحات الذكاء تلقائياً؛ يجب مراجعتها.
- بقي OCR منفصلاً عن التحليل بالذكاء الاصطناعي.

## التشغيل
1. أغلق التطبيق الحالي.
2. انسخ احتياطياً قاعدة `docuware_archive.db` ومجلد `local_archive_files`.
3. فك الضغط في مجلد جديد، وشغّل ملفات التثبيت والتشغيل.
4. افتح مركز «OCR وقراءة الملفات»، وارفع ملف PDF أو صورة.
5. بعد ظهور النص، اضغط زر تحليل الذكاء الاصطناعي الجديد.
6. تأكد من تشغيل LM Studio، تحميل نموذج يدعم العربية، وتفعيل Local Server على `127.0.0.1:1234`.

## ملاحظات
- إذا كان OCR العربي ضعيفاً، فالذكاء الاصطناعي لن يستطيع استعادة كلمات غير موجودة في النص المستخرج. يلزم التأكد من Tesseract وبيانات اللغة العربية `ara` وجودة المسح.
- هذا التعديل يضيف التحليل إلى صفحة «قراءة الملفات». مسار السلال لديه خطوة OCR/الذكاء منفصلة مسبقاً.
- تم فحص صياغة `main.py` فقط في هذه الجولة؛ يلزم اختبار الاتصال بنموذج LM Studio وملف عربي حقيقي على حاسبتك.
