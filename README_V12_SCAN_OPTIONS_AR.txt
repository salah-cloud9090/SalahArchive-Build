# V12 — أدوات مسح الكتاب والتحليل الذكي

## ما أضيف
- زر واضح «مسح الكتاب» بدلاً من تسمية المسح باسم Canon فقط.
- خيار اختيار الماسح يدوياً عبر نافذة Windows WIA؛ مفيد إذا كانت عدة تعريفات مثبتة. يعتمد ظهور الأجهزة على تعريف WIA نفسه.
- اختيار دقة PDF (150/200/300 DPI)، وجودة الضغط (60/75/85/95)، والسطوع والتباين.
- تحسين تلقائي خفيف للتباين قبل حفظ الصفحات.
- خيار تجاوز الصفحات الفارغة (محافظ لتقليل احتمال حذف صفحة باهتة).
- خيار تشغيل OCR تلقائياً بعد المسح.
- خيار تفعيل تحليل الذكاء الاصطناعي المحلي تلقائياً بعد OCR؛ الاقتراحات تحفظ للمراجعة ولا تعتمد تلقائياً في السجل الرسمي.
- تسمية خيارات السلال بوضوح.

## التثبيت الآمن
1. أغلق البرنامج القديم.
2. خذ نسخة احتياطية من `docuware_archive.db` ومجلد `local_archive_files`.
3. فك الضغط في مجلد جديد.
4. شغّل `install_dependencies.bat` ثم `run_local_archive.bat`.
5. افتح «أرشفة الكتب» ثم إعدادات «مسح الكتاب».

## ملاحظات مهمة
- اختيار الجهاز يفتح نافذة Windows WIA، ولا يمكن عرض قائمة موثوقة داخل صفحة الويب إلا إذا وفرها تعريف الماسح.
- السطوع والتباين والضغط تطبق بعد التقاط الصور؛ الدقة الفعلية أثناء المسح قد تتحكم بها نافذة/تعريف WIA.
- خيار تجاوز الصفحة الفارغة يستخدم فحصاً محافظاً جداً (صفحة شديدة البياض وقليلة التغيّر). اختبره أولاً على كتاب تجريبي؛ إذا كانت الصفحات باهتة ألغِه.
- التحليل الذكي يعتمد على OCR العربي. إذا فشل OCR أو LM Studio غير متصل، سيُحفظ المسح ويظهر توضيح للمشكلة.
- لم يتم اختبار جهاز Canon فعلياً من هذه البيئة؛ تم فحص صياغة Python فقط.
