تقرير فحص Salah Archive v16.09

الميزات التي أضيفت في هذه النسخة:
- إدارة المستخدمين: إنشاء الحساب، الاسم الظاهر، اختيار الدور، تعديل الاسم والدور، إعادة تعيين كلمة المرور، تفعيل/تعطيل.
- تأكيد كلمة مرور المسؤول مطلوب قبل فتح /users، كما أن عمليات POST الحساسة تفحص الدور وإعادة التأكيد على الخادم.
- كلمات المرور لا تعرض كنص؛ تستخدم PBKDF2-HMAC-SHA256 مع salt.
- لا يسمح بتعطيل المسؤول الحالي أو خفض صلاحية آخر مسؤول فعّال.
- يتم إبطال الجلسات المفتوحة للمستخدم بعد إعادة تعيين كلمة مروره أو تعطيل حسابه.
- ترحيل SQLite يضيف display_name بصورة إضافية آمنة؛ تحديث MySQL المرشح لم يُختبر على خادم حي.
- تحسين CSS لزر حفظ المجلس ومساحة المعاينة، مع بقاء التصميم بحاجة إلى مراجعة بصرية على Windows مقابل صور المستخدم.

اختبارات آلية مستهدفة: 15 ناجحة بعد إضافة اختبارات إدارة الحسابات.
اختبارات المجموعة الكاملة: 183 اختباراً، 3 متخطاة (قبل إعادة تشغيل المجموعة النهائية بعد تحديث التوقيع).

القيود المعروفة:
- لم يُبنَ EXE نهائي.
- لم تُجرَ تجربة فعلية على Windows 10/11.
- لم يُختبر اتصال LM Studio أو ماسح Canon/WIA أو خادم MySQL حي.
- لم يتم إثبات مطابقة واجهة المجالس للرسم المرجعي بصورة كاملة.
- اختبارات الأدوار في هذه البيئة تستخدم SQLite مؤقتة واختبارات كود؛ يلزم اختبار قبول بمتصفح Windows وحسابات تجريبية.
- لا يوجد ضمان مطلق بعدم وجود أخطاء؛ أي إصدار نهائي يتطلب اختبار بيئة المستخدم ونسخة احتياطية.
