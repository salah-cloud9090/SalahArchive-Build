Salah Archive v16.09 — مرشح اختبار

هذه حزمة مصدر اختبار مستقلة مبنية على v16.08.

التعديلات في v16.09:
- إضافة صفحة إدارة المستخدمين للمسؤول بعد إعادة تأكيد كلمة المرور.
- إضافة حساب باسم دخول واسم ظاهر وصلاحية (مسؤول / موظف أرشفة / قراءة فقط).
- تعديل الاسم والصلاحية، إعادة تعيين كلمة المرور، وتفعيل/تعطيل الحساب.
- كلمات المرور تُخزّن باستخدام PBKDF2-HMAC-SHA256 مع salt مستقل، ولا تُعرض للمسؤول.
- منع تعطيل حساب المسؤول الحالي أو خفض صلاحية آخر مسؤول فعّال.
- إنهاء الجلسات المفتوحة للمستخدم عند إعادة تعيين كلمة مروره أو تعطيل حسابه.
- إضافة اختبارات آلية لإدارة المستخدمين، مع تحسين صغير لحجم زر حفظ المجلس ومساحة المعاينة.

التشغيل الآمن:
1. فك الضغط في مجلد جديد مستقل.
2. لا تنسخ قاعدة البيانات الحقيقية ولا مفاتيح التوقيع إلى هذه الحزمة.
3. احتفظ بنسخة احتياطية من البرنامج وقاعدة البيانات قبل أي تجربة.
4. هذه الحزمة ليست EXE نهائياً؛ تشغيل Windows وCanon وLM Studio وMySQL الحي لم يتم التحقق منه في بيئة البناء.

ملاحظات الاختبار:
- اختبارات Python الآلية في هذه البيئة تغطي الدمج PDF/صور على ملفات تجريبية، سلامة المصدر، أساسيات المساعد، حماية إعدادات المسؤول، وإدارة الحسابات على SQLite مؤقتة.
- لا تعتبر نجاح الاختبارات الآلية ضماناً لعدم وجود أخطاء على كل حاسبة؛ يلزم اختبار قبول على Windows المستهدف.
