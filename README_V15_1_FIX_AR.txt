الإصدار V15.1 — إصلاح خطأ تشغيل Python

سبب الخطأ:
كان قالب معاينة المستند يحتوي على علامات اقتباس مهروبة داخل f-string متداخل، وهذا يسبب:
SyntaxError: f-string expression part cannot include a backslash
في إصدارات Python المستخدمة على بعض أجهزة Windows.

الإصلاح:
- تعديل علامات الاقتباس في حدث تعذر تحميل صورة المعاينة لتجنب backslash داخل تعبير f-string.
- فحص صياغة ملفات Python.
- فحص التوافق النحوي مع Python 3.11.

التحديث:
1. أغلق البرنامج.
2. احتفظ بنسخة من قاعدة البيانات ومجلد الملفات.
3. فك ضغط هذا الإصدار بمجلد جديد.
4. شغّل run_local_archive.bat.

ملاحظة: تم إصلاح خطأ بدء التشغيل المحدد في الصورة. يلزم اختبار بقية الوظائف على جهازك.
