نظام الأرشفة الإدارية الذكي - V7 Smart Fields (OCR + Canon WIA + MySQL migration tools)

مسح Canon المباشر:
- يتطلب Windows، وتعريف Canon يدعم WIA، ومكتبات pywin32 وPillow.
- شغّل البرنامج على نفس الحاسبة المتصلة بالماسح.
- افتح «الماسح والسلال»، اختر السلة، ثم «بدء المسح المباشر من Canon».
- ستظهر نافذة Windows WIA لاختيار الماسح/المصدر. بعد كل صفحة يسألك النظام إن كنت تريد مسح صفحة أخرى؛ تُجمع الصفحات في PDF واحد وتحفظ مباشرة في السلة.
- إذا لم يظهر الماسح، ثبّت/أصلح تعريف Canon WIA أو استخدم NAPS2 كبديل.
- المسح المباشر يعتمد على Windows WIA وليس TWAIN الخام، لأن دعم WIA يختلف بحسب موديل Canon وتعريفه.

MySQL والترحيل:
1. ثبّت MySQL Server محلياً وأنشئ قاعدة بيانات فارغة وخصص مستخدماً محدود الصلاحيات. لا تستخدم root للتشغيل اليومي.
2. افتح البرنامج > إعداد MySQL، احفظ الإعدادات واختبر الاتصال.
3. أوقف البرنامج وخذ نسخة احتياطية من docuware_archive.db ومجلد local_archive_files.
4. شغّل migrate_mysql_dry_run.bat لمراجعة الجداول وعدد السجلات أولاً.
5. بعد التأكد أن قاعدة MySQL فارغة من جداول الأرشيف، شغّل migrate_mysql_execute.bat واكتب MIGRATE للموافقة.
6. ستنشأ نسخة docuware_archive.db.pre_mysql_backup. لا تحذفها. لا تحذف مجلد local_archive_files لأن ملفات PDF والصور الأصلية محفوظة فيه.
7. الأداة تنقل جداول SQLite وسجلاتها إلى MySQL وتتحقق من أعداد الصفوف. لا تحذف أو تعدّل قاعدة SQLite الأصلية.

تنبيه مهم:
- هذا إصدار ترحيل بيانات واختبار للمسح المباشر؛ التطبيق نفسه ما زال يستخدم SQLite للتشغيل اليومي. لا تغيّر اسم/مكان قاعدة SQLite ولا تعتبر التطبيق تحول إلى MySQL بمجرد انتهاء النسخ. تفعيل MySQL كقاعدة تشغيل يتطلب تبديل طبقة الوصول للبيانات واختبارات إضافية قبل اعتمادها.
- كلمة مرور MySQL مخزنة في mysql_config.json؛ احمِ مجلد البرنامج بصلاحيات Windows، ولا تشاركه. استخدم حساباً محدود الصلاحيات.
- لا تعرض البرنامج مباشرة للإنترنت. استخدم شبكة داخلية موثوقة أو VPN.
- لا يوجد اتصال بـ DocuWare في هذا الإصدار.
