Directorate of Nationality and Civil Information — Salah Archive v15.49

التحديثات: اسم الدائرة ظاهر في شريط الواجهة؛ تم إعداد فهرس MySQL منفصل للبيانات الوصفية وحقول الفهرسة، وتبقى ملفات PDF/المرفقات كملفات مستقلة داخل local_archive_files. عند إعداد MySQL من قائمة الإعدادات، يهيئ التطبيق archive_index وarchive_index_fields ويزامن السجلات الجديدة والمعدلة والمحذوفة. SQLite يبقى قاعدة التشغيل المحلية الأساسية في هذا الإصدار؛ MySQL هنا نسخة فهرسة متزامنة وليس محرك البحث الأساسي بعد. إذا انقطع MySQL يستمر الحفظ المحلي وتُسجّل أخطاء المزامنة في mysql_index_sync.log.

الأمان والتفعيل: التفعيل دون إنترنت مرتبط ببصمة الجهاز وبمفتاح رقمي موقّع؛ إعادة التثبيت التي لا تتضمن license.key تتطلب رمز تفعيل جديداً. فحص سلامة الملفات يستخدم قائمة موقعة. احتفظ بأداة إصدار التفعيل والمفتاح الخاص خارج حزمة التوزيع.

حدود الحزمة: هذه حزمة مصدر مهيأة للبناء على Windows وليست ملف EXE جاهزاً. بناء EXE يتطلب Windows وPython 3.11 x64 وPyInstaller، أما التثبيت المستقل تماماً دون إنترنت فيتطلب حزم wheels وPython runtime وخادم MySQL محلي ضمن حزمة تثبيت مناسبة؛ هذه المكونات ليست مضمّنة بالكامل. قاعدة بيانات MySQL خدمة منفصلة يجب تثبيتها أو توفيرها على جهاز المؤسسة.

ملفات PDF لا تُحفظ داخل MySQL؛ يحتفظ الفهرس بمعلومات الملف والمسار المخزن والبصمة SHA-256 فقط. لا تحذف قاعدة SQLite أو مجلد local_archive_files قبل التحقق من النسخ الاحتياطية.
