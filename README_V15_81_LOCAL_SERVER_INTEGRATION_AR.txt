ملاحظة إصلاح مهمة من حزمة الاختبار المحدّثة:
- لتشغيل الاختبار المحلي، استخدم TEST_MYSQL_INTEGRATION_LOCAL.bat مباشرة؛ لم يعد يحتاج إلى تحرير ملف PowerShell أو إصلاح الأقواس يدوياً.
- ملف mysql_profiles.json المحلي التجريبي موجود مسبقاً بهذه الحزمة، ولا يحتوي كلمة مرور.
- بما أنك أنشأت بالفعل قاعدة الاختبار والمستخدم في MySQL Workbench، لا تعِد تنفيذ MYSQL_TEST_DATABASE_SETUP.sql؛ شغّل الاختبار المحلي وأدخل كلمة المرور الصحيحة عند الطلب.
- إذا كانت مكتبة mysql-connector-python غير مثبتة، سيعرض مشغّل الاختبار خيار تثبيتها من pip قبل الاتصال.

Salah Archive v15.81 — تكامل إعدادات MySQL المحلي والسيرفر
=========================================================

ما الجديد؟
- صفحة إعداد MySQL في المرشح تعرض إعدادين مستقلين: local وserver.
- يمكنك حفظ عنوان السيرفر المركزي لاحقاً، مع إبقاء الوضع المحلي فعالاً.
- يمكن استخدام كلمتي مرور منفصلتين عبر SALAH_MYSQL_PASSWORD_LOCAL وSALAH_MYSQL_PASSWORD_SERVER.
- كلمة المرور لا تُكتب في JSON ولا في ملف الإعداد.
- إعداد الاتصال واختبار المخطط مقيدان بقاعدة salah_archive_test فقط.
- ملف main.py الأصلي لم يتغير؛ التشغيل التجريبي يكون عبر main_mysql_candidate_v15_81.py.

طريقة الإعداد:
1. تأكد أن MySQL Server 8.4.13 وخدمة MySQL84 يعملان على حاسبتك.
2. شغّل CONFIGURE_MYSQL_PROFILES.bat. أدخل المستخدم المحلي، ويمكن ترك عنوان السيرفر فارغاً مؤقتاً.
3. أنشئ قاعدة الاختبار ومستخدم الاختبار بصلاحيات محدودة عبر MYSQL_TEST_DATABASE_SETUP.sql (في Workbench، بعد مراجعة كلمة المرور الوهمية واستبدالها).
4. شغّل START_MYSQL_TEST.bat. سيقرأ الوضع الفعال من mysql_profiles.json ويطلب كلمة المرور بشكل مخفي؛ لا يحفظها.
5. من صفحة إعداد MySQL، جرّب الاتصال وتجهيز المخطط. هذا ينشئ جداول المرشح في salah_archive_test فقط.
6. لاختبار وضع السيرفر، شغّل START_MYSQL_TEST.bat مع اختيار server من الإعدادات (أو RUN_MYSQL_TEST_SERVER.bat). يعمل التطبيق على حاسبة السيرفر ويعرض واجهة الشبكة الداخلية على المنفذ 8765. بقية الحاسبات تدخل من المتصفح إلى http://SERVER-LAN-IP:8765 بعد معرفة عنوان السيرفر.

أمان مهم:
- لا تستخدم root في التشغيل اليومي.
- لا تمنح مستخدم الاختبار DROP أو GRANT.
- لا تفتح TCP 3306 لأجهزة المستخدمين؛ الأفضل أن تتصل خدمة التطبيق على السيرفر بـ MySQL عبر 127.0.0.1، وأن تتصل الحاسبات بواجهة التطبيق على 8765 فقط.
- اسمح بمنفذ 8765 في Windows Firewall على Private LAN فقط، ولا تعرضه للإنترنت. استخدم VPN أو HTTPS reverse proxy إذا كان الوصول خارج الشبكة المحلية.
- اختيار local/server يحدد طريقة تشغيل التطبيق؛ لا ينسخ البيانات تلقائياً بين القاعدتين.
- في وضع server تبقى ملفات PDF والمرفقات مركزية داخل local_archive_files على حاسبة التطبيق، حتى يشاهدها المستخدمون عبر الخدمة المركزية.
- هذا المرشح لا يسمح بقاعدة salah_archive حتى الآن. لا تعتبره إصدار الإنتاج النهائي.

نتائج التحقق المحلية في هذه الحزمة:
- اختبارات وحدات وملفات Python بعد التعديل، مع فحص صارم لتحذيرات SyntaxWarning.
- اختبارات اختيار profile، كلمات مرور مستقلة، ومنع اسم قاعدة الإنتاج.
- لم يحدث اتصال بخادم MySQL الخاص بالمستخدم من بيئة البناء.
