Salah Archive v15.50 — تجهيز MySQL محلي دون إنترنت
================================================

النظام المستهدف: Windows 11 x64.

مهم جداً — حالة هذه الحزمة:
- تتضمن مصدر الإصدار v15.49 كما هو، مع أدوات تجهيز وتوثيق تثبيت MySQL.
- لا تتضمن ملف MySQL MSI نفسه لأن حزمة MySQL الرسمية كبيرة ويجب تنزيلها من المصدر الرسمي ونقلها إلى مجلد offline_packages.
- التطبيق الحالي ما زال يستخدم SQLite كمحرك التشغيل الأساسي. وجود سكربت ترحيل أو فهرس MySQL لا يعني أن التحويل الكامل قد تم.
- لذلك هذه حزمة تحضير وانتقال آمن وليست بعد نسخة نهائية تعمل بالكامل على MySQL وحده. لا تستبدل نسخة العمل بها كترقية إنتاجية.

1) تجهيز مثبت MySQL دون إنترنت
   أ. من جهاز متصل بالإنترنت افتح الصفحة الرسمية:
      https://dev.mysql.com/downloads/mysql/8.4.html?os=3
   ب. نزّل Windows x86 64-bit MSI: mysql-8.4.13-winx64.msi (نحو 129.9 MB).
   ج. تحقق من MD5 المنشور على صفحة MySQL: ff44ed8af9f45aca5ece06bb0db5e5db
   د. انسخ الملف إلى offline_packages بجانب هذا الملف.
   هـ. شغّل MYSQL_OFFLINE_SETUP.bat. أكمل إعداد MySQL Configurator محلياً. اختر كلمة مرور قوية لـ root ولا تضعها في ملف نصي مشترك.

2) قاعدة البيانات والملفات
   - ملفات PDF والمرفقات تبقى ملفات مستقلة داخل local_archive_files ولا تنقل إلى جداول BLOB.
   - قاعدة MySQL يجب أن تكون على 127.0.0.1 والمنفذ 3306، مع قاعدة مخصصة مثل salah_archive وقاعدة مستخدم تطبيق مستقلة بصلاحيات محدودة.
   - لا تفتح منفذ MySQL للشبكة أو الإنترنت. لا تستخدم root من التطبيق.

3) النسخ الاحتياطي قبل أي ترحيل
   - أوقف البرنامج أولاً.
   - انسخ docuware_archive.db وmysql_config.json (إن وجد) ومجلد local_archive_files إلى مجلد backup بتاريخ اليوم.
   - لا تحذف SQLite ولا تغيّر اسمها ولا تحذف local_archive_files.
   - شغّل migrate_mysql_dry_run.bat لمراجعة عدد الجداول والسجلات فقط.
   - لا تشغّل migrate_mysql_execute.bat إلا بعد إعداد MySQL وأخذ نسخة احتياطية والتحقق من ملف الإعداد.

4) الخطوة البرمجية التي ما زالت مطلوبة قبل الاعتماد
   يجب تعديل طبقة الوصول في main.py إلى MySQL، وتحويل مخطط الجداول والقيود والاستعلامات الخاصة بـ SQLite، ثم اختبار: تسجيل الدخول، إنشاء/تعديل/حذف كتاب، السلال، المجالس، المعاملات، المرفقات، السجلات، النسخ الاحتياطي والاستعادة. لا تعتمد هذا المصدر بوصفه MySQL-only حتى تنجح هذه الاختبارات.

5) ملاحظات أمان
   - احتفظ بنسخة منفصلة ومشفرة من النسخ الاحتياطية.
   - لا ترسل كلمات مرور قاعدة البيانات أو مفاتيح التفعيل عبر المحادثة.
   - ملف EXE مستقل يحتاج أيضاً إلى بناء واختبار على Windows x64، وتضمين Python runtime ومكتبات التطبيق؛ هذه الحزمة لا تدّعي أنها EXE نهائي.

المصدر الرسمي: MySQL Community Server 8.4 LTS.
