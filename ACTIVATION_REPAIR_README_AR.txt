صلاح — حزمة إصلاح التفعيل (مصدر)
=================================

التشخيص:
- الملف الذي رفعته كان يعرض إصدار 15.45، بينما license_core.py الأصلي كان يطلب 15.49؛ هذا عدم توافق حقيقي.
- الشاشة تتطلب ترخيصاً موقّعاً مرتبطاً ببصمة الجهاز. لا توجد أداة إصدار ضمن النسخة القديمة المتوفرة.
- هذه الحزمة تضبط الإصدار على 15.45 وتوفر أداة إصدار محلية بمفتاح توقيع جديد متوافق مع المفتاح العام داخل license_core.py.

محتويات الإصلاح:
- main.py هو مصدر البرنامج الذي رفعته، دون تعديل وظائف الأرشفة المقصودة.
- license_core.py يستخدم الإصدار 15.45، ويقرأ MachineGuid من مسار سجل Windows الصحيح، ثم يحفظ الترخيص في license.key.
- integrity_guard.py وقائمة سلامة الملفات أعيد توقيعهما بمفتاح مستقل.
- test_activation_flow.py يختبر إصدار الرمز والتحقق منه وحفظه في مجلد مؤقت فقط.
- BUILD_EXE_ON_WINDOWS.bat يبني نسخة محمولة على Windows باستخدام Python 3.11 x64 وPyInstaller.

اختبارات نُفذت في بيئة الفحص:
- 168 اختبار وحدة: PASS.
- فحص الصياغة البرمجية: PASS.
- اختبار SQLite معزول: PASS (13 جدولاً، عمليات إدخال/قراءة/تعديل/حذف).
- فحص سلامة الحزمة: PASS.
- اختبار تفعيل تجريبي مرتبط بالجهاز، والتحقق من المفتاح، ورفض رمز جهاز مختلف: PASS.
- اختبار MySQL حي: لم يُنفّذ في هذه الجولة؛ لا تعتبر MySQL جاهزاً للإنتاج.
- بناء EXE لويندوز على هذه البيئة: لم يُنفّذ؛ يجب تشغيل ملف البناء على Windows.

الخطوات على Windows:
1. فك ضغط الحزمة إلى مجلد جديد. لا تفكها فوق النسخة المثبتة ولا تحذف ملفاتك.
2. ثبّت Python 3.11 x64. ثبّت المتطلبات: py -3.11 -m pip install -r requirements.txt
3. ثبّت PyInstaller إذا لم يكن موجوداً: py -3.11 -m pip install pyinstaller
4. شغّل BUILD_EXE_ON_WINDOWS.bat وانتظر ظهور dist\SalahArchive\SalahArchive.exe.
5. شغّل EXE من داخل مجلد dist\SalahArchive كاملاً، لا تنقل EXE وحده.
6. انسخ رمز الجهاز من شاشة التفعيل.
7. على جهاز الإدارة الآمن فقط، شغّل ADMIN_ONLY_KEEP_PRIVATE\ISSUE_KEY.bat والصق رمز الجهاز. انسخ المفتاح الناتج إلى شاشة التفعيل على الجهاز المطابق.
8. احتفظ بمجلد ADMIN_ONLY_KEEP_PRIVATE في مكان آمن ومقيد؛ لا تنسخه إلى مجلد البرنامج المثبت أو حاسبة الدوام ولا ترسله للآخرين.
9. اختبر الدخول والوظائف الأساسية. لا تستبدل النسخة الحالية حتى تنجح التجربة وتؤخذ نسخة احتياطية من قاعدة البيانات ومجلد الملفات.

حماية البيانات:
- لا تحذف docuware_archive.db ولا local_archive_files من النسخة الحالية.
- لا تجرّب ترحيل MySQL على قاعدة الإنتاج. إعداد MySQL في هذا المشروع لا يزال يحتاج اختباراً حياً مستقلاً.
- مفتاح التفعيل خاص بهذا المشروع ويجب حمايته مثل أي مفتاح توقيع.

ملاحظة: الحزمة مصدر وليست EXE جاهزاً. لا أستطيع تأكيد عمل EXE على حاسبتك قبل بنائه وتشغيله على Windows لديك.
