الإصدار 15.22 — توضيح خيار تدبيس دفعة الاستيراد

تم توضيح مربع الاختيار في صفحة «أرشفة الكتب > المسح والسلال»:
- يظهر داخل بطاقة مميزة بلون وحدود واضحين، مع مربع اختيار كبير.
- العنوان: «تدبيس الملفات المختارة معاً».
- شرح الاستخدام: فعّله إذا كانت الملفات تمثل كتاباً واحداً متعدد الصفحات، واتركه فارغاً إذا كانت كتباً مستقلة.
- زر الاستيراد صار أوضح، مع تذكير بأن الصور المصغرة تظهر بعد الاستيراد لتحديد الكتب.
- لم تتغير قاعدة البيانات أو آلية التدبيس الخلفية؛ التغيير يخص وضوح الواجهة.
تم فحص صياغة ملفات Python فقط؛ يلزم تجربة واجهة Windows للتأكد من المظهر النهائي.
قبل التحديث: أوقف البرنامج وخذ نسخة احتياطية، ثم فك الحزمة في مجلد مستقل وشغّل START_HERE.bat.
