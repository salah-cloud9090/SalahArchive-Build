الإصدار 15.8 — إصلاح الفهرسة اليدوية والمعاينة

التعديلات:
1. إذا فشل OCR والذكاء المحلي، يبقى الكتاب في السلة وتظهر رسالة واضحة تسمح بإكمال الفهرسة اليدوية.
2. جميع حقول الفهرسة قابلة للتحرير، ولا يشترط نجاح OCR أو الذكاء لحفظ الكتاب.
3. عند فشل الحفظ، يرجع زر العودة إلى نفس الكتاب من السلة بدلاً من فقدان سياق الفهرسة.
4. إصلاح نوع المحتوى عند فتح الملف الأصلي، خصوصاً PDF، حتى يستطيع المتصفح عرضه كـ PDF.
5. تحسين رسالة خطأ المعاينة وتوجيه المستخدم إلى تثبيت PyMuPDF وPillow عند الحاجة.

التثبيت:
- أوقف النسخة القديمة.
- فك الحزمة الجديدة داخل مجلد مستقل.
- شغّل install_dependencies.bat ثم run_local_archive.bat.
- لا تنقل قاعدة البيانات فوق الأصل قبل أخذ نسخة احتياطية. إذا كنت تريد متابعة سجلاتك الحالية، أوقف التطبيق وانسخ docuware_archive.db ومجلد local_archive_files من مجلدك الحالي إلى مجلد الإصدار الجديد فقط بعد أخذ نسخة إضافية.

حدود الاختبار: فُحصت صياغة Python وتوفر مكتبة PyMuPDF في بيئة التطوير. يجب تجربة ماسح Canon وملفات PDF الحقيقية على الحاسوب المستهدف.
