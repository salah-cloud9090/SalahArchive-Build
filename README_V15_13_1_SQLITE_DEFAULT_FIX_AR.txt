الإصدار 15.13.1 — إصلاح تعطل صفحة أرشفة الكتب

سبب الخطأ:
كان تعريف created_at في جداول مجموعات السلال يستخدم DEFAULT (datetime("now"))، وهو تعبير افتراضي لا يقبله SQLite. تم تغييره إلى DEFAULT CURRENT_TIMESTAMP.

التحديث:
- تم إصلاح جميع مواضع إنشاء جداول مجموعات الكتب في main.py.
- تم فحص صياغة جميع ملفات Python.
- تم اختبار أوامر إنشاء الجداول على SQLite بنجاح.

التثبيت:
1. أوقف النسخة الحالية.
2. فك ضغط هذه النسخة في مجلد جديد مستقل.
3. شغّل install_dependencies.bat ثم run_local_archive.bat.
4. لا تشغّل reset_test_database.bat؛ لا حاجة لمسح قاعدة البيانات.
5. إذا كانت قاعدة بياناتك موجودة في مجلد النسخة القديمة، انسخها احتياطياً قبل نقلها، ولا تستبدلها بقاعدة فارغة.
