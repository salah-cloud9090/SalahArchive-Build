إصلاح Salah Archive v15.81 - فحص مخطط MySQL

سبب المشكلة:
ملف المخطط يعرّف الفهرس idx_local_docs_subject بالشكل subject(191)، لكن محلل الفحص كان يتوقف عند القوس الداخلي ويقرأ الفهرس خطأً كأنه subject بلا طول بادئة.

ما تم إصلاحه:
- إصلاح محلل الفهارس ليتعامل مع الأقواس المتداخلة وأطوال البادئة.
- نجحت الاختبارات البرمجية الـ164.
- اجتاز فحص سلامة الملفات.
- لم يتم الاتصال بقاعدة بياناتك أو تعديلها أثناء الإصلاح.
- لم يتم حذف قاعدة الاختبار أو إعادة إنشائها تلقائياً.
- قاعدة الإنتاج لم تُفتح ولم تُستهدف.

الخطوة التالية:
شغّل TEST_VIRTUAL_SERVER_MYSQL.bat من هذه الحزمة، ثم أرسل تقرير MYSQL_LIVE_INTEGRATION_RESULT_SERVER.json الجديد. هذا الإصلاح يعالج سبب الخطأ الظاهر، لكنه لا يُعد إثباتاً لنجاح اتصال MySQL الحي حتى يعاد الاختبار على حاسبتك.
