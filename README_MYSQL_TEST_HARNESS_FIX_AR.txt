Salah Archive v15.81 — إصلاح أدوات اختبار MySQL في Windows
=====================================================

מטרה
----
חבילה זו מתקנת את מפעילי הבדיקה ב-Windows כדי להימנע מהשגיאות שהתקבלו במעטפת PowerShell. קובצי ה-BAT מפעילים כעת את מפעיל Python החדש ישירות; הם אינם תלויים ב-Test-SalahArchiveMySQL.ps1.

מצב ההגדרות
-----------
- mysql_profiles.json כלול עם פרופיל local ללא סיסמה: 127.0.0.1:3306, משתמש archive_test_app, בסיס salah_archive_test.
- לא נשמרה בחבילה סיסמה. המפעיל מבקש את הסיסמה במצב מוסתר.
- ملف تعريف server يبقى غير مهيأ إلى أن يُدخل عنوانه الحقيقي.

طريقة الاختبار المحلي
---------------------
1. فكّ الحزمة إلى مجلد جديد.
2. تأكد أن خدمة MySQL84 تعمل.
3. شغّل TEST_MYSQL_INTEGRATION_LOCAL.bat.
4. إذا كان mysql-connector-python غير مثبت، سيعرض المشغّل خيار تثبيته باستخدام pip؛ وافق فقط إذا كان هذا الاتصال مسموحاً على جهازك. يحتاج التثبيت اتصال إنترنت أو حزمة متاحة محلياً.
5. أدخل كلمة مرور archive_test_app عند الطلب. الإدخال مخفي ولا يُحفظ في JSON أو سطر الأوامر.
6. يجهز الاختبار مخطط salah_archive_test، ثم ينفذ عمليات الإدخال والبحث والتعديل وربط اضبارة ومرفق والتراجع والحذف، ويكتب MYSQL_LIVE_INTEGRATION_RESULT_LOCAL.json.

ملاحظات فنية
------------
- هذه نسخة اختبار قبل الإنتاج، وليست إصداراً موقعاً رسمياً.
- لا تعتمد على CHECK_MYSQL_OFFLINE.bat كاختبار تكامل؛ وظيفته فقط فحص وجود mysql.exe وخدمة Windows. لم يعد عدم وجود mysql.exe في PATH يمنع تشغيل اختبار Python.
- أدوات الاختبار مقيدة برمجياً بقاعدة salah_archive_test؛ إذا كان ملف الإعداد يشير إلى قاعدة أخرى، يتوقف المشغل قبل تشغيل الاختبار.
- اختبارات الوحدة والـ smoke test لا تقومان باتصال MySQL حي. لا نعلن نجاح الاختبار الحي إلا عندما ينتج التقرير MYSQL_LIVE_INTEGRATION_RESULT_LOCAL.json بحالة PASS على الحاسبة التي يعمل عليها MySQL.
- main.py الأصلي لم يتغير؛ المرشح main_mysql_candidate_v15_81.py تجريبي وغير موقّع رسمياً.
