توضيح حالة حاجز MySQL — v15.53.2
=================================

مهم: هذا الملف يصحح أي انطباع سابق بأن حاجز mysql_safety.py مدمج في التطبيق.

- توجد وحدة mysql_safety.py واختبارات محلية لها.
- لكن main.py المعتمد هنا أُعيد إلى النسخة المطابقة للبيان الموقّع، لذلك لا يستورد هذه الوحدة ولا يطبق الحاجز داخل شاشة MySQL.

- لا تستخدم إعداد MySQL في التطبيق الحالي لتجربة كتابة حتى يتم دمج الحماية وإعادة توقيع الإصدار.
